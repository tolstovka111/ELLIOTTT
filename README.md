# ELLIOTT·studio — сайт-портфолио

Портфолио веб-студии: тёмная тема с liquid glass, интерактивная чёрная дыра и живые демо-анимации.

## Страницы

- **index.html** — главная: hero с интерактивной чёрной дырой (canvas), обо мне, цены на сайты, этапы работы, преимущества, контакт в подвале (Telegram [@nysh4real](https://t.me/nysh4real)).
- **lab.html** — примеры анимаций: переключатель темы «Окно» (день/ночь), лампа с формой входа, симуляция погоды с грозой, кнопка заказа с грузовиком.

## Фичи

- Навигация-«пилюля» в правом верхнем углу с раскрывающимися кнопками и переключателем тёмной/светлой темы (сохраняется в localStorage)
- Liquid glass стиль: blur, полупрозрачность, скользящие блики
- Чёрная дыра: аккреционный диск из частиц, фотонное кольцо, реакция на курсор и клик
- Reveal-анимации при скролле, магнитные кнопки, бегущая строка
- Без сборки и зависимостей — чистые HTML/CSS/JS, готово для GitHub Pages
