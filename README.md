# Elliot Editor — фото- и аудио-редактор эффектов

Два инструмента, всё локально в браузере — без серверов и загрузок:

- **`index.html` — фото-редактор**: загрузи фото, накрути эффекты, скачай PNG/JPEG/WEBP.
- **`audio.html` — Audio Mixer**: закинь аудио или видео, обработай звук и скачай WAV/MP3. Фиолетовая тема.
- **`design.html` — My Design**: интерактивное 3D-стекло в тёмно-зелёной с чёрным гамме — скруглённые плиты (clip-path: path с дугами) с минтовыми фасками висят на разной глубине наклонённой в перспективе поверхности, следуют за курсором, ловят блик и ломают надпись Elliot Design на швах; клик заставляет стекло вздрогнуть. При низком FPS автоматически включается лайт-режим.

## Эффекты фото-редактора

Пикселизация · Яркость · Контраст · Насыщенность · Глитч · Шум ·
RGB-сдвиг (хроматическая аберрация) · Сканлайны (VHS) · Виньетка ·
Золотой тон · Чёрно-белое · Инверсия — плюс 5 готовых пресетов.

## Эффекты Audio Mixer

Скорость · Тон голоса (гранулярный питч-шифт) · Реверб (Шрёдер) ·
8-бит/бит-краш · Дисторшн · Эхо · Под водой · Тремоло — плюс 5 пресетов
(CHIPMUNK, DEMON, 8BIT, CAVE, DIVER). Принимает аудио и видео (берёт
звуковую дорожку), обработка по сэмплам на чистом JS, прослушивание
через Web Audio с перемоткой кликом по волне (плейхед и прогресс),
экспорт WAV (16-бит PCM, LIST INFO с названием/исполнителем) или MP3
(lamejs в `js/lame.min.js` + ID3v2.3-теги: название, исполнитель,
обложка). Поля «Исполнитель» и «Название трека» и обложка задаются
перед сохранением, из них же строится имя файла.

## Фишки

- Фон «жидкое золото» — WebGL-шейдер (домен-варпинг fbm-шума), воссоздаёт референс-видео и анимируется бесконечно без швов.
- 3D-элементы: вращающиеся кубы и кольца, наклон карточки за курсором; в подвале — белый самолётик Telegram, который парит и «взлетает» при наведении (ссылка на @pighig).
- Звук: разные синтезированные звуки интерфейса (WebAudio) — глитч-клик у кнопок, блип у пресетов, мягкий тон у ссылок, тик у слайдеров — и джингл (`sounds/export-done.mp3`) после экспорта.
- Экспорт в полном разрешении исходника с выбором формата (PNG / JPEG / WEBP): превью считается на уменьшенной копии, при экспорте тот же конвейер применяется к оригиналу.
- Пиксельная 3D-типографика: Press Start 2P и Handjet (кириллица) лежат локально в `fonts/` — сайт работает офлайн, заголовки с 3D-экструзией.
- Чёрно-жёлто-белый стиль, кнопки — чистый текст с RGB-глитчем при наведении, адаптив, поддержка `prefers-reduced-motion`.

## Навигация

Сверху на всех страницах — expanding hover menu (`menu.css`): пилюля с тремя
иконками IMG Editor / Audio Mixer / My Design; при наведении кнопка плавно
расширяется и выезжает подпись, активный раздел подсвечен фирменным цветом.

## Запуск

Статические файлы, сборка не нужна:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или просто открыть `index.html` в браузере.
