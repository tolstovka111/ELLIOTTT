# ELLIOTTT

## Fake Stars — плагин для exteraGram

`fake_stars.py` — плагин, который **визуально** показывает любое количество Telegram Stars
и позволяет «оплачивать» ими покупки. Всё происходит только на вашем устройстве.

### Что умеет

- **Свой баланс звёзд.** Число задаётся в настройках плагина (или выбирается пресетом) и
  подставляется везде, где приложение показывает баланс: шторка Stars, профиль, формы оплаты,
  подарки.
- **«Оплата» звёздами.** Покупки, подарки и платные реакции проходят локально: запрос на сервер
  не отправляется, вместо ответа сервера приложение получает поддельный успешный результат.
- **Списание.** После каждой «оплаты» локальный баланс уменьшается на цену — чтобы ощущение было
  как от настоящей траты. Отключается тумблером.
- **Уведомления.** Плашка с суммой после каждой фейковой оплаты (тоже отключается).

### Чего плагин не делает

- Не меняет баланс на серверах Telegram — там остаётся ваш настоящий.
- Собеседники ничего не видят: подарок, реакция или покупка существуют только у вас на экране,
  потому что запрос никуда не уходит. При перезапуске приложения «купленное» исчезнет.
- Не трогает покупку самих звёзд за деньги (Google Play / карта) — эти запросы проходят как обычно.

### Установка

1. Скачайте `fake_stars.py`.
2. Отправьте файл себе в «Избранное» и нажмите на него → **Установить плагин**.
   Либо: **Настройки → exteraGram → Плагины → «+» → выбрать файл**.
3. Включите плагин и откройте его настройки шестерёнкой.

Требуется exteraGram 11.9+ (API плагинов 12.x — основная цель).

### Настройки

| Настройка | Что делает |
|---|---|
| Подменять баланс звёзд | Главный тумблер отображения фейкового баланса |
| Количество звёзд | Само число (только цифры) |
| Быстрый выбор | Пресеты 1 000 … 1 000 000 000 |
| Применить сейчас | Записывает число в приложение и перерисовывает интерфейс |
| Фейковая оплата | Перехватывать `sendStarsForm` и платные реакции |
| Списывать с фейкового баланса | Уменьшать число после «оплаты» |
| Уведомлять об «оплате» | Показывать плашку с суммой |

### Как это устроено

- **Xposed-хук** на `StarsController.getBalance()` / `balanceAvailable()` — подменяет то, что
  интерфейс получает из кэша клиента (`TL_stars.StarsAmount` в новых сборках, `long` в старых).
- **`post_request_hook`** на `TL_payments_getStarsStatus` и соседние ответы — переписывает поле
  `balance` в ответе сервера, чтобы после каждого обновления баланс оставался фейковым.
- **`on_update_hook`** на `updateStarsBalance` — то же самое для пуш-апдейтов баланса.
- **`pre_request_hook`** на `TL_payments_sendStarsForm` и `TL_messages_sendPaidReaction` — вместо
  отправки запроса возвращает собранный `TL_payments_paymentResult` с пустым `TL_updates`
  (`HookStrategy.MODIFY_FINAL`); цена берётся из заранее сохранённой формы оплаты
  (`TL_payments_getPaymentForm`) или из поля `count` платной реакции.

Все обращения к Java обёрнуты в `try/except` с логом, поэтому расхождения в именах классов между
версиями клиента отключают конкретный механизм, а не ломают плагин целиком.
